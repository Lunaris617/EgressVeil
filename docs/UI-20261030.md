# LuCI 界面与主题调整

EgressVeil 配置页原先在服务器渲染过程中同步执行完整接管检查，单项实测7.319秒。现改为异步、限时和30秒缓存，仍保留保存应用及服务启动时的严格检查。真实登录后测得配置页HTTP200约0.271秒，状态接口HTTP200约0.152秒。状态显示独立span，保留检查时间；配置提交后清理旧状态缓存。

校园网仅移除1280px宽度上限，并对主题内容容器作局部适配；当前设备基于部署前真实JS文件修改，未覆盖本地其他未提交功能。对应补丁为patches/campusnet-fluid-width.patch。

新增官方源Footstrap（与现有LuCI同版）及作者发布的Alpha 3.9.7_beta2-r10、配置组件2.1-r1。第三方APK已与作者发布页SHA256比对，未强制覆盖或升级系统依赖。Argon仍是当前主题，可在系统→系统→语言和界面选择。

未重构建完整固件，本次是现机界面热修复。
