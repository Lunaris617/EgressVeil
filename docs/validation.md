# 1.0.0 验证记录

本版以 2026-10-30 实体路由器部署后修正并实际使用的方案为基线，不再使用最初仅在 Clash 出口改写的方案。发布过程只读取现机程序，未在生产路由器上安装发行包。

## 现机与发行包一致性

从现机读取白名单内的程序及公开资源，逐项比较 372 个文件的 SHA256。UA3F、Mihomo、接管脚本、桥接保护和 LuCI 页面均一致。设备 UCI、订阅、节点、认证信息、日志和抓包不属于发布基线。

签名 APK 解包后再次核对同一清单：372 项一致，程序文件不允许组或其他用户写入。默认订阅为空，首次安装不自动启用功能。具体清单见 [runtime-baseline.json](../release/runtime-baseline.json)。

## 本次实体部署结果

| 项目 | 结果与证据范围 |
|---|---|
| 前置 UA | LAN fake-IP 代理 HTTP 及本机公网 HTTP，经接收端确认收到配置的 UA；在代理加密前改写 |
| 最终出口 | 保留双入口、防环标记及最终 TCP 处理；不把 HTTPS 内层 UA 算作改写结果 |
| IPv4 TTL | WAN 采样 160 包：TCP 111、UDP 47、ICMP 2，均为 64；抓包内核丢包为 0 |
| UDP | STUN Binding 事务成功；不能据此宣称真实跨网 P2P 通过 |
| Hysteria2 | 定向 HTTPS 请求成功；用户确认实际恢复。保留订阅原始链接证书指纹，不固化用户指纹 |
| OpenClash 概览 | WebSocket 连续收到 5 帧，用户确认统计不再闪回零 |
| 配置界面 | 表单不等待完整健康检查；测得页面约 0.271 秒，状态请求约 0.152 秒，非性能保证 |
| 桥接恢复 | 纳入现机对 post-apply-audit-failed 状态的恢复修复，未放宽就绪审计 |

## 隔离发行包检查

APK 使用独立发行密钥签名，已通过严格验签及离线解包检查。发行公钥公开，私钥不进入仓库或交付目录。控制网关与严格 HTTP/h2c 引擎的当前源码单元测试再次通过。由于恢复隔离环境所需的 Windows 挂载确认未完成，本次没有重跑最终签名 APK 的虚拟机升级安装；该项标为未验证，不能以解包校验替代。现机功能结果来自已部署的同字节运行文件。

旧开发版的八种开关组合、HTTP/h2c、界面和生命周期结果保留在 [0.2.0 记录](validation-0.2.0.md)，仅供追溯；其中“代理内层 UA 保留原值”的旧行为已由前置改写替代，不能作为本版验收结论。

## 边界

以上是有限样本与已用拓扑的结果，不表示所有时间、协议、网卡均不存在泄露。未验证 IPv6、PPPoE、VLAN、多物理 LAN、其他实体网卡、独立跨网 P2P 及长期负载。HTTPS 不解密，非 HTTP 设备标识和 TCP 时间戳不统一。没有商业生产认证或完整安全审计。
